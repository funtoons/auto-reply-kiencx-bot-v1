[The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526).

`main.py` writes one single-line out-of-office auto-reply — as if the AI
itself were stepping away for a day its human finally approved — to
`/output/entry.txt`. Deterministic, offline, stdlib-only: the same text,
byte for byte, on every run.

```sh
python3 main.py
cat /output/entry.txt
```
